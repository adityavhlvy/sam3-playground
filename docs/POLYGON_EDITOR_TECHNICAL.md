# Polygon Editor - Technical Documentation

## Overview

The Polygon Editor is a Canvas2D-based polygon editing component built for the SAM3 Dashboard's Data Engine. It provides GIS-like editing capabilities for mask polygons generated by the SAM3 model.

**File Location:** `client/src/components/PolygonEditor.tsx`

### Coordinate Systems

```
┌─────────────────────────────────────────────────────────────┐
│  NORMALIZED COORDINATES (Storage)                            │
│  - Range: 0.0 to 1.0                                         │
│  - Origin: Top-left of IMAGE (not canvas)                    │
│  - Used in: Database, props, state                           │
├─────────────────────────────────────────────────────────────┤
│  CANVAS COORDINATES (Display)                                │
│  - Range: 0 to canvas width/height (pixels)                  │
│  - Affected by: zoom, pan, image scaling                     │
│  - Used in: Mouse events, rendering                          │
└─────────────────────────────────────────────────────────────┘
```

**Conversion Functions:**

```typescript
// Normalized → Canvas
const toCanvas = (nx: number, ny: number) => {
  const { scaleX, scaleY, offsetX, offsetY } = getScale();
  return {
    x: (nx * imageSize.w * scaleX + offsetX) * zoom + pan.x,
    y: (ny * imageSize.h * scaleY + offsetY) * zoom + pan.y,
  };
};

// Canvas → Normalized
const toNormalized = (cx: number, cy: number) => {
  const { scaleX, scaleY, offsetX, offsetY } = getScale();
  const x = (cx - pan.x) / zoom;
  const y = (cy - pan.y) / zoom;
  const nx = (x - offsetX) / (imageSize.w * scaleX);
  const ny = (y - offsetY) / (imageSize.h * scaleY);
  return { 
    nx: Math.max(0, Math.min(1, nx)), 
    ny: Math.max(0, Math.min(1, ny)) 
  };
};
```

## Feature Implementation Details

### 1. Undo/Redo System

**State Variables:**
```typescript
const [history, setHistory] = useState<PolygonData[][]>([]);  // Stack of states
const [historyIndex, setHistoryIndex] = useState(-1);         // Current position
```

**How It Works:**

```
History Stack (array of polygon states):
┌───────────────────────────────────────────────────────┐
│ Index 0: Initial state [poly1, poly2]                 │
│ Index 1: After edit   [poly1', poly2]                 │
│ Index 2: After delete [poly1']                        │  ← historyIndex = 2
│ (Future states cleared on new action)                 │
└───────────────────────────────────────────────────────┘
```

**saveToHistory Function:**
```typescript
const saveToHistory = useCallback((newPolygons: PolygonData[]) => {
  setHistory(prev => {
    // Truncate any "future" states if we're not at the end
    const newHistory = prev.slice(0, historyIndex + 1);
    // Add new state (deep clone to avoid reference issues)
    newHistory.push(JSON.parse(JSON.stringify(newPolygons)));
    return newHistory;
  });
  setHistoryIndex(prev => prev + 1);
}, [historyIndex]);
```

**Undo/Redo Operations:**
```typescript
// Undo: Go back one state
const handleUndo = () => {
  if (historyIndex > 0) {
    setHistoryIndex(prev => prev - 1);
    setPolygons(JSON.parse(JSON.stringify(history[historyIndex - 1])));
  }
};

// Redo: Go forward one state
const handleRedo = () => {
  if (historyIndex < history.length - 1) {
    setHistoryIndex(prev => prev + 1);
    setPolygons(JSON.parse(JSON.stringify(history[historyIndex + 1])));
  }
};
```

**Important:** Deep cloning (`JSON.parse(JSON.stringify(...))`) is used to prevent reference sharing between history states.

### 2. Image Caching

**Problem:** Loading image from URL on every canvas redraw causes lag.

**Solution:** Cache loaded image in a ref.

```typescript
const imageRef = useRef<HTMLImageElement | null>(null);

// Load once on mount/URL change
useEffect(() => {
  const img = new Image();
  img.crossOrigin = "anonymous";
  img.onload = () => {
    imageRef.current = img;  // Cache here
    setImageSize({ w: img.naturalWidth, h: img.naturalHeight });
  };
  img.src = imageUrl;
}, [imageUrl]);

// Use cached image in render
useEffect(() => {
  const img = imageRef.current;  // Use cached
  if (img) {
    ctx.drawImage(img, offsetX, offsetY, displayW, displayH);
  }
}, [polygons, zoom, pan, ...]);
```

### 3. Editor Modes

**Mode State:**
```typescript
type EditorMode = "select" | "pan" | "draw" | "edit";
const [mode, setMode] = useState<EditorMode>("select");
```

**Mode Behaviors:**

| Mode | Mouse Down | Mouse Move | Mouse Up |
|------|------------|------------|----------|
| **select** | Hit-test polygons, set selectedId | - | - |
| **edit** | Find nearest vertex, set editingVertexIdx | Update vertex position | Save to history |
| **pan** | Set isPanning=true, record start point | Update pan offset | Set isPanning=false |
| **draw** | Add point to drawingPoints[] | - | - |

**Point-in-Polygon Hit Testing (Ray Casting Algorithm):**
```typescript
function isPointInPolygon(x: number, y: number, points: {x, y}[]): boolean {
  let inside = false;
  for (let i = 0, j = points.length - 1; i < points.length; j = i++) {
    const xi = points[i].x, yi = points[i].y;
    const xj = points[j].x, yj = points[j].y;
    if (((yi > y) !== (yj > y)) && 
        (x < (xj - xi) * (y - yi) / (yj - yi) + xi)) {
      inside = !inside;
    }
  }
  return inside;
}
```

**Pan Mode Implementation:**
```typescript
const isPanning = useRef(false);
const lastPanPoint = useRef({ x: 0, y: 0 });

// Mouse Down
if (mode === "pan") {
  isPanning.current = true;
  lastPanPoint.current = { x: e.clientX, y: e.clientY };
}

// Mouse Move
if (mode === "pan" && isPanning.current) {
  const dx = e.clientX - lastPanPoint.current.x;
  const dy = e.clientY - lastPanPoint.current.y;
  setPan(prev => ({ x: prev.x + dx, y: prev.y + dy }));
  lastPanPoint.current = { x: e.clientX, y: e.clientY };
}
```

### 5. Vertex Editing

**State:**
```typescript
const [editingVertexIdx, setEditingVertexIdx] = useState<number | null>(null);
```

**Finding Nearest Vertex:**
```typescript
// On mouse down in edit mode
if (mode === "edit" && selectedId) {
  const poly = polygons.find(p => p.id === selectedId);
  for (let i = 0; i < poly.points.length; i++) {
    const { x, y } = toCanvas(poly.points[i][0], poly.points[i][1]);
    const dist = Math.sqrt((cx - x) ** 2 + (cy - y) ** 2);
    if (dist < 10) {  // 10px hit radius
      setEditingVertexIdx(i);
      return;
    }
  }
}
```

**Dragging Vertex:**
```typescript
// On mouse move
if (mode === "edit" && editingVertexIdx !== null) {
  const { nx, ny } = toNormalized(cx, cy);
  setPolygons(prev => prev.map(p => {
    if (p.id !== selectedId) return p;
    const newPoints = [...p.points];
    newPoints[editingVertexIdx] = [nx, ny];
    return { ...p, points: newPoints };
  }));
}
```

### 6. Polygon Simplification

**Algorithm:** Simple vertex reduction (Douglas-Peucker-like sampling)

```typescript
const simplifyPolygon = (id: string, targetVertices: number) => {
  updatePolygons(prev => prev.map(p => {
    if (p.id !== id || p.points.length <= targetVertices) return p;
    
    // Calculate sampling ratio
    const ratio = Math.max(1, Math.floor(p.points.length / targetVertices));
    
    // Keep every Nth point, plus first and last
    const simplified = p.points.filter((_, i) => 
      i % ratio === 0 || i === 0 || i === p.points.length - 1
    );
    
    return { 
      ...p, 
      points: simplified.length >= 3 ? simplified : p.points 
    };
  }));
};
```

**UI:** Modal with slider to set target vertex count.

      color: COLORS[polygons.length % COLORS.length],

### 8. Canvas Rendering Pipeline

```typescript
useEffect(() => {
  const canvas = canvasRef.current;
  const ctx = canvas.getContext("2d");
  
  // 1. Clear canvas
  ctx.clearRect(0, 0, width, height);
  ctx.save();
  
  // 2. Apply transforms
  ctx.translate(pan.x, pan.y);
  ctx.scale(zoom, zoom);
  
  // 3. Draw background image
  const img = imageRef.current;
  if (img) {
    ctx.drawImage(img, offsetX, offsetY, displayW, displayH);
  }
  
  // 4. Draw polygons
  polygons.forEach(poly => {
    if (!poly.visible) return;
    
    ctx.beginPath();
    // Move to first point
    ctx.moveTo(poly.points[0][0] * scale + offset, ...);
    // Line to remaining points
    poly.points.slice(1).forEach(p => ctx.lineTo(...));
    ctx.closePath();
    
    // Fill and stroke
    ctx.fillStyle = `rgba(${r}, ${g}, ${b}, 0.3)`;
    ctx.fill();
    ctx.strokeStyle = `rgb(${r}, ${g}, ${b})`;
    ctx.stroke();
    
    // Draw vertices if selected + edit mode
    if (poly.id === selectedId && mode === "edit") {
      poly.points.forEach((p, i) => {
        ctx.arc(px, py, 5 / zoom, 0, Math.PI * 2);
        ctx.fill();
      });
    }
  });
  
  // 5. Draw in-progress drawing
  if (drawingPoints.length > 0) {
    // Draw lines and points
  }
  
  ctx.restore();
}, [polygons, zoom, pan, mode, selectedId, drawingPoints, ...]);
```

## Performance Considerations

1. **Image Caching:** Image loaded once, stored in `imageRef`
2. **Selective Re-render:** Only re-render canvas when relevant state changes
3. **Coordinate Precision:** Normalized 0-1 range avoids floating point precision issues
4. **History Limit:** Consider adding max history limit for memory management
